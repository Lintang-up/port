# Lintang Portfolio

Template portfolio responsif menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak folder.
2. Buka `index.html` di browser, atau jalankan Live Server dari VS Code.

## Bagian yang perlu kamu personalisasi
- Ganti `YOUR PHOTO HERE` di `index.html` dengan foto sendiri. Cara mudah: letakkan foto bernama `profile.png` di folder ini, lalu ganti blok `.portrait-placeholder` menjadi `<img class="profile-photo" src="profile.png" alt="Foto Lintang">`.
- Ganti `hello@example.com` dengan email aktif di `index.html`.
- Perbarui tautan sosial media dan tambahkan link GitHub pada tiap proyek.
- Ubah warna utama melalui variabel `--accent` dan `--accent2` di bagian `:root` pada `style.css`.
- Edit nama, deskripsi, skill, pengalaman, dan data proyek sesuai kondisi terbaru.

## Fitur
- Mobile-first responsive layout
- Dark theme dengan aksen ungu yang mudah dikustomisasi
- Scroll reveal animation dan smooth scrolling
- Custom cursor untuk perangkat pointer
- Navigasi mobile
- Slide-out project detail panel
- Tombol copy email
- Menghormati `prefers-reduced-motion`

Tidak menggunakan framework. Google Fonts membutuhkan koneksi internet.
